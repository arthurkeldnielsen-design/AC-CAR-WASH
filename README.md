# AC Car Wash

Static website for AC Car Wash (three pages: Services, Contact, About). The site is intended to be published with GitHub Pages (or any static host).

Expected Pages URL after publishing:

https://arthurkeldnielsen-design.github.io/AC-CAR-WASH/

How to publish (short):
1. Go to your repo Settings → Pages
2. Source: branch `main` and folder `/ (root)`
3. Save and wait a minute; the site will be live at the URL above.

SEO tips: add a repo description, a README (this file), and keep meaningful page titles and meta descriptions (already added).
